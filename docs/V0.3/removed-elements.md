# Removed or replaced elements

The previous dense technical dashboard has been replaced visually by a mockup-oriented weather dashboard.

## Replaced

- Metric list panel replaced by the location sidebar.
- Current-value technical card replaced by the current-weather hero card.
- Subscription table and feed moved out of the main visual surface for this UI iteration.
- Provider reference tables moved to the provider contract and model documentation.

## Preserved in code

- Supported metric listing.
- API/provider limit listing.
- Current-value request.
- Subscribe and unsubscribe operations.
- Simulated provider implementation.

## Intentionally not included

- Font binaries.
- Gradients.
- Drop shadows.
- Blur effects.
- Heavy animations.
