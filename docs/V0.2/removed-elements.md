# Removed elements

This UI/UX iteration removes visual noise from the previous dashboard shape:

- left-side metric browser from the default screen;
- always-visible provider detail tables;
- update feed list;
- gradients;
- drop shadows;
- translucent panels;
- oversized three-column split layout.

The removed information is not lost. Supported metrics and provider limits remain available in the `Reference` tab, while live stream updates are summarized in the active-stream table.
